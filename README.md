
El Impostor — Edición Argentina

Una web para jugar al clásico "juego del impostor" con tus amigos, con categorías y palabras bien argentinas (comida, lugares, fútbol, jerga, personajes populares y más).

¿Cómo funciona?

Cargá los nombres de los jugadores, elegí las categorías que quieras usar y cuántos impostores va a haber.
La web genera un link único para la partida.
Mandás ese link al grupo (una sola vez). Cada uno lo abre desde su propio celular, toca su nombre y ve su carta: la palabra secreta, o si le tocó ser el impostor, una pista para disimular.
Jugás la ronda como siempre: pistas, discusión y votación, cara a cara con tus amigos.

¿Quieren jugar otra ronda? No hace falta volver a cargar todo: solo tocá "Generar otra partida", copiá el nuevo link y mandalo al grupo de nuevo.

Extras: ruleta para sortear quién arranca la ronda, y podés armar todas las partidas que quieras sin límite.

No hace falta instalar nada ni crear una cuenta — funciona 100% en el navegador, sin servidores ni guardar datos de nadie.
